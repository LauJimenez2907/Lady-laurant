
# PROYECTO LADY LAURANT

## 1. Nombre del proyecto
Lady Laurant - Detalles hechos con amor.

## 2. Descripción
Lady Laurant es una página web creada para mostrar y ofrecer productos personalizados y regalos elaborados a mano.

El sitio permite a los clientes conocer los productos, consultar sus precios, agregarlos al carrito de compras y realizar pedidos mediante WhatsApp.

## 3. Objetivo general
Desarrollar una página web para dar a conocer los productos de Lady Laurant y facilitar la comunicación con los clientes.

## 4. Objetivos específicos
- Mostrar un catálogo de productos.
- Permitir la búsqueda de productos.
- Organizar los productos por categorías.
- Implementar un carrito de compras.
- Conectar la página con una base de datos.
- Facilitar los pedidos mediante WhatsApp.

## 5. Tecnologías utilizadas
- HTML: estructura de la página.
- CSS: diseño y estilos.
- JavaScript: funciones e interactividad.
- Node.js: entorno de ejecución.
- Express: servidor y API.
- MongoDB: almacenamiento de productos.
- Mongoose: conexión y manejo de datos.

## 6. Público objetivo
Personas interesadas en comprar regalos, detalles personalizados y productos elaborados a mano.

## 7. Resultado esperado
Una página web funcional, organizada y adaptable a diferentes dispositivos.
