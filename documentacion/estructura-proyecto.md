
# ESTRUCTURA DEL PROYECTO

El proyecto Lady Laurant está dividido en dos partes principales:

## Backend
Contiene los archivos encargados del servidor y la conexión con la base de datos.

- config/: configuración de MongoDB.
- models/: estructura de los productos.
- controllers/: funciones para gestionar productos.
- routes/: rutas de la API.
- server.js: archivo principal del servidor.

## Frontend
Contiene los archivos que permiten visualizar e interactuar con la página.

- intex.html: estructura principal.
- style.css: estilos de la página.
- script.js: funciones de JavaScript.
- admin/: panel administrativo.
- chatbot/: asistente de atención.
- imagenes/: imágenes del proyecto.

## Documentación
Contiene los documentos que explican el proyecto y su funcionamiento.

## Archivos principales
- package.json: información y dependencias del proyecto.
- package-lock.json: registro de dependencias instaladas.
- .env: variables de entorno.
- .gitignore: archivos que Git no debe subir.
